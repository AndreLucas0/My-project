# AR Mechatronic Cell

Protótipo acadêmico desenvolvido em Unity 6 para demonstração de Realidade Aumentada aplicada à visualização e manutenção de uma célula mecatrônica.

## Objetivo

Demonstrar, de forma simples, como um modelo 3D de uma célula mecatrônica pode ser visualizado e manipulado em um ambiente de Realidade Aumentada.

## Tecnologias

* Unity 6
* C#
* AR Foundation
* plataforma AR compatível com o dispositivo-alvo

## Funcionalidades

A implementação deverá contemplar:

* modelo 3D simplificado da célula;
* seleção de componentes;
* informações dos componentes;
* interação simples de manutenção;
* posicionamento da célula em AR;
* manipulação básica da célula;
* build para dispositivo móvel.
